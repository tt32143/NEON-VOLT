# NEON VOLT — финална листа за тестирање

Оваа листа мора да се помине на компјутерот на кој ќе се демонстрира проектот. Статичка проверка на кодот не е замена за browser тест.

## 1. Инсталација и build

```bash
node -v
npm -v
npm install
npm run build
npm run preview
```

- [ ] `npm install` завршува без грешка.
- [ ] `npm run build` завршува и создава `dist/`.
- [ ] Preview URL се отвора во Chrome или Edge.
- [ ] Нема црвени грешки во DevTools Console.

## 2. Седум задолжителни техники

- [ ] Осветлување: провери Ambient, Directional, Spot/Point светла и видливи сенки.
- [ ] Color management: провери дека боите се правилни и дека нема warning за color space.
- [ ] Текстури: смени боја; приближи се до каросеријата и подот за да ја видиш суптилната текстура.
- [ ] PBR: ротирај го автомобилот и провери метални рефлексии на каросеријата/бандажите.
- [ ] ShaderMaterial: набљудувај го анимираниот прстен околу платформата.
- [ ] Animation: вклучи/исклучи Auto rotate и провери дека shader/light анимацијата продолжува.
- [ ] Raycaster: hover и кликни неколку делови; кликни празен простор; притисни Escape.

## 3. Интерфејс и пристапност

- [ ] Пробај ги четирите camera presets и кратенките 1–4.
- [ ] Смени ги сите четири бои и трите lighting режими.
- [ ] Вклучи/исклучи Grid и Auto rotate.
- [ ] Користи Tab и Enter за навигација низ копчињата; провери видлив focus.
- [ ] Префрли на друг browser tab и врати се; анимацијата треба да продолжи без голем скок.
- [ ] Провери responsive распоред на прозорец со помала ширина.
