# NEON VOLT — финална листа за проверка и предавање

<small>Статус: завршено. Оваа листа ги сумира проверките што студентот ги извршил и ги потврдил пред финализирање на проектот.</small>

## 1. Инсталација, build и верификација

- [x] Проектот е инсталиран со npm dependencies.
- [x] `npm run verify` — успешно; 7/7 задолжителни техники и потребните проектни датотеки се препознаени.
- [x] `npm run build` — успешно генериран production build.
- [x] `npm run preview` — production preview серверот успешно стартуван.

## 2. Седум задолжителни графички техники

- [x] Осветлување: Ambient, Directional, Spot и Point светла; сенките се визуелно проверени.
- [x] Color management: sRGB и ACES Filmic Tone Mapping се имплементирани.
- [x] Текстури: Color Map, Normal Map и UV координати се имплементирани; текстурите се визуелно проверени.
- [x] PBR: metalness, roughness и environment reflections се имплементирани; рефлексиите се визуелно проверени.
- [x] Custom ShaderMaterial: vertex deformation и animated color на светлосниот прстен.
- [x] Animation: delta-time анимација и easing; платформата и светлосните ефекти се проверени.
- [x] Interaction: Raycaster hover, избор на компоненти и чистење на селекцијата со Escape.

## 3. Функционалност на апликацијата

- [x] Промена на бојата на автомобилот.
- [x] Сите четири camera presets: Hero, Front, Side и Top.
- [x] Сите три lighting режими: STUDIO, PULSE и NIGHT.
- [x] Auto Rotate Platform — вклучување и исклучување.
- [x] Technical Grid — вклучување и исклучување.
- [x] Focus Vehicle.
- [x] Escape — чистење на селекцијата.
- [x] Промена на големината на Chrome прозорецот.
- [x] Стабилност во текот на рачна сесија од приближно 2–3 минути без забележано замрзнување.
