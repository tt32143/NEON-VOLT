# NEON VOLT — записник од рачно тестирање

## Опсег
Овој записник бележи проверки што корисникот ги извршил во Chrome со Vite development server и ги потврдил во разговорот. Ова е корисничка потврда, не автоматски лабораториски тест.

## Што сè уште не е потврдено

- `npm run build` / production build не е потврден во работната околина на асистентот, бидејќи `npm install` истече при преземање на зависностите.
- Оваа табела не е доказ за тестирање на секоја можна графичка картичка, browser верзија или оперативен систем.
- Reduced Motion, WebGL context-loss и keyboard-only accessibility остануваат дополнителни тестови од checklist.

## Препорачана финална проверка на компјутерот на студентот

Од терминалот во root директориумот на проектот:

```bash
node -v
npm -v
npm install
npm run verify
npm run build
npm run preview
```

Потоа отвори го Preview URL во Chrome и провери DevTools → Console. Ако `npm install` или `npm run build` врати грешка, зачувај го целиот текст на грешката за дијагностика.

## Важна академска напомена

Пред предавање, студентот треба лично да го пополни `AI-USE.md` со сопствените проверки, измените што ги направил и што научил. Не треба да се претставува AI-генериран опис како лично научено без студентот навистина да го разбира.
