# NEON VOLT — записник од рачно тестирање

## Опсег
Овој записник бележи проверки што корисникот ги извршил во Chrome со Vite development server и ги потврдил во разговорот. Ова е корисничка потврда, не автоматски лабораториски тест.

## Резултати од дополнителните проверки

Следниве проверки се извршени од студентот на локален Windows компјутер и се потврдени во разговорот:

| Проверка | Резултат |
|---|---|
| `npm run verify` | PASS — 7/7 задолжителни техники и потребните проектни датотеки |
| `npm run build` | PASS — production build успешно генериран |
| `npm run preview` | PASS — Preview серверот успешно стартуван |

Production build е генериран со Vite 7.3.7. При build се појавува предупредување дека JavaScript bundle е поголем од 500 kB (534.48 kB; gzip 136.15 kB). Ова е предупредување за големината на bundle-от, а не неуспешен build.

## Ограничувања на тестирањето

- Рачното тестирање е извршено во Google Chrome на конкретниот Windows компјутер на студентот.
- Резултатите не претставуваат доказ за тестирање на секоја можна графичка картичка, browser верзија или оперативен систем.
- Reduced Motion, WebGL context-loss и целосна keyboard-only навигација не се евидентирани како посебно потврдени рачни тестови.
- `npm run verify` е статичка проверка на датотеки, imports и маркери во изворниот код; не е замена за browser тестирање.

## Важна академска напомена

Пред предавање, студентот треба лично да го пополни `AI-USE.md` со сопствените проверки, измените што ги направил и што научил. Не треба да се претставува AI-генериран опис како лично научено без студентот навистина да го разбира.
